# Discord Presence Studio

Personalize sua atividade do Discord com textos, imagens, botões, cronômetros, presets e muito mais — sem precisar de token ou qualquer coisa similar.

## Baixar para Windows

### [⬇️ Clique aqui para abrir o download mais recente](https://github.com/paqyoun/discord-presence-studio-releases/releases/latest)

Na página que abrir:

1. Procure a seção **Assets**.
2. Baixe o arquivo que começa com **DiscordPresenceStudio-Setup**.
3. Abra o arquivo `.exe` e conclua a instalação.

> Você não precisa ter uma conta no GitHub.

## Qual arquivo devo baixar?

- **Setup `.exe`** — versão recomendada. Instala normalmente no Windows.
- **Portable `.exe`** — funciona sem instalação.
- **Não baixe:** `latest.yml`, `.blockmap` ou “Source code”. Esses arquivos são usados pelo sistema de atualização.

## Atualizações

Depois da instalação, o próprio Discord Presence Studio verifica novas versões e avisa quando houver uma atualização disponível.

---

Este repositório contém somente os downloads e arquivos necessários para as atualizações automáticas. O código-fonte não.
